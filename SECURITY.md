# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue ni un PR público. Usa el reporte privado de GitHub:
pestaña **Security** > **Report a vulnerability** de este repositorio.

Se responde en un plazo razonable; el proyecto lo mantiene una sola persona.

## Alcance

Solo la última versión en `main`. No hay versiones anteriores con soporte.
